# Votre Site Rapide

construis le site de "website.gg" inspire toi grandement du design de @project:d559aa5a-332c-4057-8f33-8124b7952bfc:"snow.gg" . Website.gg est une website agency alsacienne proposant des sites web clé en main avec nom de domaines .fr et .com. Les sites sont construits pour 120 euros en 7 jours puis 40 euros de maintien support, hébergement et renouvellement du nom de domaine par an. Première étape : le client fournit logo, liens, articles, images, texte à intégrer, contexte prix enfin la totale. Précise que sans ces informations nous ne pourrons pas avoir un site fiable, il faut donc donner le plus d'infos pour la meilleure qualité. Etape 2 : le client choisit son nom de domaine : intègre une recherche rdap pour indiquer au client si le nom souhaité est pris ou pas. Troisième étape ( à intégrer stripe plus tard) le client paye les 100 euros par carte avec une intégration stripe. Quatrième étape : Le premier site est présenté au client sois par lien sois par appel discord ou google meet. Si le client demande des modifications c'est l'étape 5 nous retravaillerons les modifications sous 5 jours. A savoir qu'il ny'a que deux vagues de modifications supplémentaires incluses. Nous intègrerons des sites d'exemples pour le design plus tard avis client checkout espace client plus tard. J'oubliais mais le client doit fournir un site qui lui plait niveau design et une palette de couleurs pour mener au mieux le projet
