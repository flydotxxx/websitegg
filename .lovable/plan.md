# Pages Design et Domaine

## Objectif
Ajouter deux pages publiques cohérentes avec l’identité sombre actuelle de website.gg.

## `/design`
- Reprendre le croquis fourni : une colonne de sélection à gauche et un aperçu web actif à droite.
- Ajouter cinq réalisations cliquables : NU.MK, Hou.ee, Musiq3.com, dieltiens.fr et dnb.band.
- Afficher le nom, une description courte, le domaine et un lien d’ouverture pour chaque projet.
- Charger le site sélectionné dans une fenêtre intégrée ; forcer le chargement du site dans la fenêtre intégrée.
- Ajouter l’accès à cette page dans la navigation et le pied de page.

## `/domain`
- Créer une page éditoriale dédiée aux noms de domaine, structurée pour la recherche web.
- Expliquer simplement le rôle d’un domaine, les extensions `.fr` et `.com`, le choix d’un bon nom, l’enregistrement, le renouvellement et l’accompagnement website.gg.
- Réutiliser le vérificateur RDAP et enrichir le résultat affiché avec les informations disponibles du registre.
- Ajouter l’accès à cette page dans la navigation et le pied de page.

## Détails techniques
- Créer deux routes TanStack distinctes avec titres, descriptions et métadonnées sociales uniques.
- Étendre le résultat RDAP avec les dates et statuts utiles sans exposer de données personnelles.
- Utiliser les composants et couleurs sémantiques existants, avec une mise en page adaptée au mobile.
- Vérifier les deux pages, les interactions, les liens et la recherche RDAP dans l’aperçu.
